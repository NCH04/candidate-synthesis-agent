# AI Candidate Synthesis Agent — live demo

A multi-agent recruitment assistant that turns a CV, a technical test sheet and
free-form interview notes into one standardized, citation-backed, bias-checked
candidate report.

**This demo runs on pre-computed sample data.** No AI calls are made and nothing
you upload is processed or stored — click *Run sample evaluation* to see a full
report for a sample candidate. The real pipeline (FastAPI + Claude, eight agents,
live SSE streaming) runs against the Anthropic API and is documented in the
source repository.

👉 **Source, architecture and setup: https://github.com/NCH04/candidate-synthesis-agent**
